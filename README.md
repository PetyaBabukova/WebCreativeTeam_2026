# WebCreativeTeam 2026

Двуезичен Next.js/Express сайт със статична начална страница по одобрения мокъп. Публичните страници са `/bg`, `/en`, `/about/bg` и `/about/en`. Един Node процес обслужва страниците, Next ресурсите и Express endpoint-ите на един порт.

## Изисквания и стартиране

- Node.js 22 (локално проверен с 22.14.0) и npm 10.9.2. Версиите на зависимостите са заключени в `package-lock.json`: Next.js 16.3.6, React 19.3.0, Express 5.2.1 и TypeScript 5.9.3.
- `npm ci`
- `npm run dev` — общият сървър с Next HMR и автоматичен restart при промени в `server/`.
- Отворете `http://localhost:3000`; `/` пренасочва временно към `/bg`. Стойностите по подразбиране за host, порт и маршрути са в `lib/config.ts`. `PORT` задава порта, а `SITE_URL` — публичния origin за metadata.

Production стартът е `npm run build`, последван от `npm start`. За Render Web Service използвайте същите build/start команди с Node 22 и една услуга; тук не се създава или променя отдалечена услуга.

| Настройка | Значение |
| --- | --- |
| `PORT` | Порт от 1 до 65535; по подразбиране 3000. Сървърът слуша на `0.0.0.0`. |
| `NODE_ENV` | `development` за `npm run dev`, `production` за `npm start`; задава се от командите. |
| `SITE_URL` | Публичен HTTP(S) origin за canonical и езиковите адреси, например `https://example.com`; локално по подразбиране `http://localhost:<PORT>`. Без път, query, fragment или credentials. |

## Проверки

```text
npm run typecheck
npm run lint
npm test
npm run test:coverage
npm run build
npm run test:e2e:install
npm run test:e2e
```

E2E тестовете стартират собствен production сървър на конфигурирания тестов порт (сега 3100); той трябва да е свободен. Локалната команда за Chromium използва стандартния Playwright cache, както и тестовете. За Linux CI е настроено инсталиране на Chromium със системните му зависимости. Frontend и backend coverage имат отделни отчети в `coverage/` и отделен минимум 80% за lines, statements, functions и branches.

## Текущ обхват

Използват се директни suffix маршрути и два locale root layout-а с общи компоненти. Началната страница следва предоставения мокъп и използва локалните изображения от `2026_Redesign/Assets/`. Логото в `public/logo.svg` е предоставеният вариант `logo_2026_DARK_HORIZONTAL.svg` за тъмен фон. Фонът, централният обект, информационните панели и текстът в hero секцията са отделни елементи; същото важи за изображенията и текста в останалите секции. Засега страницата е статична: видеото, стрелките на услугите и връзките към проектите нямат целеви страници. Анимациите ще се добавят след преглед на оформлението. Страницата „За нас“ все още е базова.

Непознатите публични адреси връщат истински HTML 404, а `/api` адресите — JSON 404. `/healthz` показва готовността на Next/Express; не проверява база данни. Страниците са с `noindex`. **Преди публикуване премахнете `noindex` от metadata**, иначе страниците няма да се индексират. В production задайте правилния публичен `SITE_URL`, иначе canonical адресите ще сочат към локалния default. Няма база данни, администрация, форми, CMS или миграция на стария сайт. Стойностите за резултатите на проектите и контактният имейл са взети от мокъпа и очакват потвърждение преди публикуване.

Подробният обхват и проверките са в [плана за скелета](doc/01-application-skeleton.md), а по-широката цел — в [архитектурния план](doc/ARCHITECTURE.md).
